This is a placeholder article, included so `/en/articles/` and `/en/blog/` have something to display and so the collection's format is easy to copy. Delete this file (or edit it in place) once you have real writing to publish.

## How to add a real article

1. Add a new file to `_posts/` named `YYYY-MM-DD-your-title.md`.
2. Give it front matter with `layout: post`, a `title`, `lang` (`en`, `ua`, or `ru`), a `date`, and optionally an `excerpt`.
3. Write the article body in Markdown below the front matter.
4. Push to GitHub — Netlify rebuilds the site automatically, and the article appears on `/{lang}/articles/` and `/{lang}/blog/`, sorted newest first.

Articles are meant to run long (1,500–3,000 words) — case analyses, deeper HealthTech thinking, anything that needs room. For something shorter, use a note instead (see `_notes/`).
