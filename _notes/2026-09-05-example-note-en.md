This is a placeholder note. Notes are quick (300–500 words) — a shift observation, a link, a half-formed idea worth keeping. Add a file to `_notes/` named `YYYY-MM-DD-your-title.md` with `layout: note`, a `title`, `lang`, and a `date`, then write below the front matter. It will show up on `/en/notes/` and `/en/blog/` automatically.
